FairFare

An auto-rickshaw fare checker. Enter your trip and what the driver asked for, and FairFare tells you if it's fair or excessive, based on official city rates.

View source on GitHub How to run

How it works

Five steps from pickup point to verdict.

1

Enter the trip

Choose the city, pickup point and destination.

2

Get the distance

Looked up from the built-in route table, or typed in by hand.

3

Calculate the fare

Minimum fare + per-km rate, plus waiting and night charges.

4

Compare

Checks the driver's demand against the official fare.

5

Verdict + history

FAIR or EXCESSIVE, and every check is saved.

The fare formula

Rates are set per city and can be updated in the app.

Distance fare = minimum fare + (distance − minimum km) × per-km rate Waiting = waiting minutes × waiting rate Night charge = night % × distance fare (only during night hours) Official fare = total, rounded to the nearest rupee

Worked example: Kochi, 6 km, 10 min waiting, at night

Kochi rates: Rs 30 for the first 1.5 km, then Rs 15/km, Rs 1/min waiting, 50% extra from 22:00 to 05:00.

ItemCalculationAmount
Distance fare30 + 4.5 × 15Rs 97.50
Waiting charge10 × 1Rs 10.00
Night charge50% of 97.50Rs 48.75
Official fareroundedRs 156
Driver demandedRs 200
EXCESSIVEDriver asked Rs 44 more than the official fare

How to run

FairFare is a Java desktop app. It runs on your computer with JDK 11 or newer, and needs no other libraries.

# Windows
build.bat
run.bat

# Linux / macOS
./build.sh
./run.sh

# Fare logic tests
java -cp out fairfare.FareLogicTest
